## Problems and fixes
- VM `LD_LIBRARY_PATH` puts CUDA 13.2 first: torch loaded cuDNN 9.23 instead of its own (9.10 / 9.7). Conv still ran, but
  fragile. `finetune.sh` unsets it; `run_vla_server.sh` starts the server with `env -u LD_LIBRARY_PATH` (verified: no
  LD_LIBRARY_PATH in the server process).
- `HF_HOME` pointing at `~/hsim_data/hf-cache` hides the token (it lives in `~/.cache/huggingface/token`): set
  `HF_TOKEN_PATH` in the scripts (no copy of the secret).
- Disk: smoke/probe runs were 31 GB each (deleted). N1.6 checkpoint with optimizer = 22 GB, without = 9 GB, final model 9.2 GB.
  `finetune.sh` now: save every 5000 steps, keep 2 checkpoints, N1.7 `--save-only-model` (no resume), N1.6 deletes
  optimizer.pt from all but the newest checkpoint. Expected per run: N1.6 ~40 GB, N1.7 ~28 GB (estimate).
- Skill rate: synchronous chunk requests paused the arms (16.8 Hz) -> async prefetch; then found the real limit is Python
  GIL contention (camera deserialization + executor threads). Final loop: clock-driven on the ROS clock (sim time),
  one sleep per slot, 2 executor threads -> 18.0 Hz with correct timing (late slots skipped, never stretched).
- rclpy `JointState.position` is `array.array`: assign lists, don't extend.
- Test harness: piping `ros2` output into grep hung (the ros2 daemon inherits the pipe); write to files instead.

## Decisions
- NEW_EMBODIMENT, not REAL_G1: REAL_G1 expects real G1 + Dex3 hands, wrist-EEF actions and whole-body nav commands;
  our data is sim G1 + Dex1 grippers, standing, joint space. Config follows REAL_G1's style: arms RELATIVE, grippers ABSOLUTE.
- 16-step action chunks (0.8 s at 20 Hz), execute 8, video `ego_view` only (wrist cams optional in the converter).
- Server returns ABSOLUTE joint targets (GR00T `unapply_action` adds the relative arm actions back onto the state).
- HTTP+JSON server (stdlib) rather than GR00T's ZMQ server, so the ROS client needs no extra packages (PNG via zlib).
- pick(X)+place(Y) in a plan -> one Manipulate goal (v1 policy is trained on whole pick-and-place instructions).
